# B3.1 新产品 EEPROM 烧录及实机验收步骤（Keil MDK5）

**适用**：V1.0.4_B31，STM32L151 主控，AT24C512 64KiB。

## 第一部分：烧录前核对

1. 使用新装或经工装确认可清除并已整片擦为 `0xFF` 的 AT24C512。不能仅通过 Keil 内部 Flash 下载完成外接 EEPROM 擦除；外接 EEPROM 是另一颗 I2C 芯片。
2. 对照硬件确认 AT24C512 I2C A0/A1/A2 引脚使地址为 7 位 `0x50`（HAL 使用 `0xA0`），确认 WP 脚处于允许写入的状态。芯片后缀、工作电压及 I2C 上拉仍需以实际硬件为准。
3. 解压本工程，用 **Keil MDK5** 打开 `STM32L151/MDK-ARM/STM32L151.uvprojx`；选择正确目标与 ST-Link，确保 ARM Compiler 与 STM32L1 Device Pack 已安装。
4. 打开 `Software/inc/App_Eep.h` 确认两项服务宏均为 `0`，不得启用旧迁移服务。通过 `Project → Rebuild all target files` 编译，再 `Flash → Download`。**不要直接烧录 ZIP 内历史生成的 HEX/AXF。**

## 第二部分：Keil Watch 验证

在 main.c 的 `B3_Eeprom_Boot_OK = Eep_Data_Get();` 后设置断点，执行一次，进入调试 Watch，观察：

| 变量 | 新空白芯片首次初始化成功 | 正常第二次上电 | 异常情况 |
|---|---:|---:|---|
| `B3_Eeprom_Boot_OK` | 1 | 1 | 0 |
| `Debug_Eep_Storage` | 1（有效 B3 标定） | 1 | 2 / 4 / 5 |
| `Debug_Eep_Record` | 2（暂无记录） | 2；若已记录则通常 1 | 3 / 4 等 |
| `Debug_Eep_Warnings` | 0 | 0 | 仍为 0（旧迁移已删除） |

状态解释：`Storage=2` 非空无有效 B3 标定且被锁定；`Storage=4` 标定日志损坏；`Storage=5` 读写/I2C 异常。`Record=3` 是记录元数据损坏；`Record=4` 是 I2C 读取失败。这些状态都不可当成“芯片空白”直接覆盖。

## 第三部分：必须完成的六组实机验证

1. **首次初始化**：接入真正空白芯片，第一次上电应得到 Boot_OK=1、Storage=1；使用专用 I2C 工装读取 `0xE000` 与 `0xE080`，应看到 `GJB3` 魔数、有效 CRC 和各自 `0xA5` 提交标志。不能简单靠 Debug 变量证明双份物理写入成功。
2. **重启不重写**：同一 EEPROM 再次断电上电，标定参数应从 EEPROM 读回且不被默认参数重写；可用 I2C 抓包或工装比对两个 64 字节快照，确认上电没有新写入。
3. **人工标定持久化**：分别执行 CG/GJ/CH 标定，最后按存储键；每次成功蜂鸣后断电上电，使用 Watch 观察 `CG_Param`、`GJ_Param`、`CH_Param` 对应值，与保存值相符；修改密码再验证一次。标定操作必须使用标准器具。
4. **非空白保护**：备用 EEPROM 的任意地址若存在未知非 `0xFF` 数据而校准区没有有效快照，则上电 Boot_OK 应为 0，Storage=2，且不应写入或清除任何字节。不得用实际客户芯片做破坏性实验。
5. **写保护/掉电故障**：用专门测试样机验证 WP 阻止写入时不会报保存成功；在备用测试芯片上安排首次初始化或人工保存过程的受控掉电测试，复位后要么恢复有效副本，要么停止写入报错，不能出现“数据校验失败仍当成功”。
6. **记录区域隔离**：通过测试调用 `Eep_Input_Node(index,node)` 顺序写入至 100 条，验证 `Eep_Get_Node_Count`、`Eep_Output_Node` 与清空接口；检查标定快照、记录数快照、记录数据互不覆盖，101 条应拒绝。注意现有用户界面并未自动调用 `Eep_Input_Node()`。

## 第四部分：关于生产装配及故障芯片

- 如果芯片不是严格全 `0xFF`，本版不会擅自把它当作新芯片。对已经确认可以删除的试产芯片，使用外部工装整片清空后再让新版固件初始化。
- 如果检测到两份 B3 标定都坏，或读取失败，本版不自动覆盖疑似用户标定。应通过维护工装检修芯片及供电，不要通过强行设置旧服务宏绕过保护。
- 如果单次初始写入中断，并且残留数据**完全符合**本版出厂初始快照且其他区域都为空，程序允许自动继续；不符合条件时不会尝试修复写入。

**提醒**：EEPROM 启动错误时程序会尝试发出三声蜂鸣，但当前主界面仍可能显示 RAM 默认参数；此时不能把仪表视为已经标定合格，不得交付测量使用。

**验收状态**：当前已进行主机端模拟测试，未进行实物 Keil 编译、烧录、抓包或掉电验收。以上步骤需由设备现场执行并记录通过结果后，才能标注“实机量产通过”。
