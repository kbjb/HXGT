# CG38 TEST 查照间隔与护背距离

2026-11-23。基于 c97c4e9 / CG37 TEST，主控 STM32L151，配套现有 CG34 TEST 倾角板。

## 烧录与适用范围

主控固件为 `firmware/CG38_TEST_20261123/STM32L151_CG38_TEST.hex`，开机显示 CG38 TEST。倾角板已经是 CG34 TEST 的样机只更新主控。本次没有修改或重新发布倾角板固件，也没有执行硬件烧录。

首次使用本版，请先确认轨距标定有效，再重新进行查护标定，并完成下面的实机检查。历史查护参数可能来自旧版单帧采集，出厂默认的 10000/13000 也不是这把尺子的实测标定结果。

本版采用“共用位移换算斜率、查照和护背各自标定基准”的模型。需要验证尺子的三种接触方式确实具有相同传动比例和方向。已提供的 ATGJ-1 左右测量块照片能看到 1435 标记和开口结构，但没有尺子测头的接触姿态，也不能据照片确认 43/44 mm 的实际尺寸。1391/1348 测量面及放置方法应以本机有效说明书、检定证书和实际测头结构核实。本版是待实机验证的测试版，不代表精度或检定合格结论。

## 实时计算与滤波

倾角板继续按 100 ms 调度读取位移，确认新转换后执行原滤波：旧结果 × 0.5 + 本次采样 × 0.5；串口每 100 ms 上报。轨距、查照、护背均使用同一份已滤波的 `GJ_Ad`，查护没有增加测量滤波、死区或等待窗口。

主控从轨距 1410/1435/1470 三点的原线性最小二乘算法取得斜率 k（mm/AD）。原正常轨距换算算式保留，查护计算为：

```text
查照 = 1391 + k × (GJ_Ad - CH_Param.CZ_Ad)
护背 = 1348 + k × (GJ_Ad - CH_Param.HB_Ad)
```

AD 差值用有符号 32 位计算，低于基准时不会发生无符号回绕。两个基准 AD 可以都为 10318，不用两者之差拟合斜率。两者相等本身不能证明测头放置正确，仍需用已知尺寸变化验证。更改轨距标定后，需复核并重新标定查护。

查护使用与轨距相同的一位/两位小数设置，直接更新实际换算值。数字用固定宽度一次覆盖，避免旧位数残留和每次更新前整行清空。链路超时显示 NO SENSOR，存储异常显示 EEP ERROR，位移 AD 为 0 或超过 32767 显示 AD ERROR，基准或轨距标定无效显示 CAL ERROR。

沿用轨距现有模型，没有新增温度补偿；标定温度仍保存并检查有效范围。当前协议没有单独的 ADS1110 转换有效性字段，串口帧新鲜不等于能够证明传感器每帧都完成了一次新转换。

## 查护标定流程

先确认轨距三个标定值已实际保存并能断电重读。轨距原标定流程本次未改，它原来的“成功”画面之后还需再按一次存储键，才调用 EEPROM 保存；不能仅凭该旧提示判断轨距已保存。

按确认过的测头接触方式建立查照 1391 mm、护背 1348 mm 基准。程序只负责采集 AD，不能识别尺子是否放在正确测量面。

| 操作顺序 | 操作和界面 | 数据状态 |
| --- | --- | --- |
| 进入 | CZ 1391mm，实时 AD，WAIT/READY | 清空本次稳定采集窗口 |
| 第一次存储键 | READY 后采集查照，显示 CAP 和 CAPTURED | 十帧均值暂存在 RAM，尚未写 EEPROM |
| 第二次存储键 | 切换到 HB 1348mm，重新等待 READY | 清空窗口，随后按护背姿态放置并稳定 |
| 第三次存储键 | READY 后采集护背，显示 CAP 和 CAPTURED | 护背均值暂存在 RAM |
| 第四次存储键 | 显示 SAVE? 和存储键保存提示 | 等待最终提交，尚未成功 |
| 第五次存储键 | EEPROM 写入、读回与 CRC 校验通过后显示“成功”和 SAVED | 完成提交，新参数立即生效 |
| 第六次存储键 | 返回标定菜单 | 流程结束 |

AD 行在采集前后持续更新；CAP 行是本次采集值，不随实时 AD 变化。EEPROM 失败显示 EEP ERROR 并停留在最终提交页，可以重试。未稳定、断线或温度/轨距参数无效时不推进采集状态。退出再进入会重新开始采集，不写入未完成的标定。

## 标定稳定参数

这些参数仅用于按键采集，不影响正常测量的响应。位置为 `STM32L151/Software/inc/agreement_head.h`。

| 参数 | 本版测试值 | 含义 |
| --- | --- | --- |
| CH_CAL_STABLE_SAMPLES | 10 | 最近十个校验正确的位移报告 |
| CH_CAL_STABLE_TIME_MS | 800 ms | 十帧跨度下限，正常约 900 ms |
| CH_CAL_MAX_GAP_MS | 250 ms | 帧间断档重置窗口，最后一帧超时不采集 |
| CH_CAL_STABLE_RANGE_MM | 0.03 mm | 十帧最大值减最小值的毫米换算上限 |
| CH_CAL_MAX_MEAN_DRIFT_MM | 0.01 mm | 前五帧与后五帧均值差的毫米换算上限 |

0.03/0.01 mm 是本次测试起始参数，尚未经过本机噪声验证，不是精度承诺。阈值按实际轨距斜率换算，未照搬超高 AD 门槛。

WAIT DATA 为帧数不足，WAIT TIME 为跨度不足，WAIT NOISE 为峰峰值过大，WAIT DRIFT 为缓慢移动，WAIT LINK 为短时断档；NO SENSOR 为总体链路超时，GJ CAL ERROR 为轨距标定不能提供有效斜率。

Keil Watch 可观察 `GJ_Ad`、`CH_Param`、`CH_Param_Temp`、`CH_Calibration_Range_AD`、`CH_Calibration_Range_MM`、`CH_Calibration_Trend_MM`、`CH_Calibration_Wait_State` 和 `CH_Cal_Save_Failed`。后者 0=无失败，1=保存失败，2=标定/温度无效，3=断线，4=采集未稳定。

## 实机验收记录

1. 更新主控并确认 CG38 TEST。进入查护测量页，改变测头位移，检查示值持续变化。
2. 核对轨距三点参数，按正确测量面完成查护标定。两项同为 10318 时应可提交，最终必须看到 SAVED。
3. 分别回到 1391/1348 基准，记录示值；用检定器配套量杆/块规建立附近至少一个较小和一个较大尺寸，验证方向、变化量和误差。按当前接触姿态读取对应项目。
4. 每项取下重新放置至少五次，记录标准值、实时 AD、示值、最大误差和重复性；固定不动记录波动，改变尺寸记录稳定时间。
5. 正常保存后断电重启，复测两项基准与附近尺寸，确认参数与结果可复现。
6. 观察 WAIT 原因是否符合实际。READY 很难出现时记录峰峰值/漂移诊断，再决定是否调整标定阈值。
7. 复测原轨距及超高的水平、左右 180 mm，确认原功能。

主机测试中的断线、写保护和断电故障是模拟注入，没有在用户设备上进行故障实验。实际误差、重复性、响应时间及 OLED 观感仍需用户实机验证。

## EEPROM 兼容与回退

保留 B3.1 地址、槽大小、CRC 和 A/B 提交流程，未清空 EEPROM。新增查护写入检查：两个 AD 各自为 1～32767，温度在有效范围内；读取历史结构继续兼容。取消了两个 AD 必须不同的规则。

**保存相同 AD 后，不宜直接回刷 CG37 或更早固件。** 旧版会把这份完整标定快照判为无效，可能回退到较旧的整份快照，或显示 EEPROM 错误，涉及轨距、超高等同一快照中的参数。如需回退，应先备份完整 EEPROM，并使用包含“允许查护相同 AD”修正的兼容回退固件。
