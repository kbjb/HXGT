# CG41 TEST 电量、时钟和蓝牙

## 电量与一次欠压提示

主板 PB1 使用 ADC 通道 9。分压按图中 R24 100 kΩ、R25 33 kΩ和实物取消 LM358 的接法计算。修改阻值或告警电压时编辑 `STM32L151/Software/inc/adc_head.h`。LM95071 继续测倾角板温度。主板从 STM32L151CBT6A 的 `VREFINT_CAL_ADDR_CMSIS`（0x1FF80078）读取出厂校准字。校准条件为 VDDA 3.0 V。校准码异常时，使用数据手册典型参考电压 1.224 V 估算，`Battery_Vref_Fallback` 标记回退。

采电池电压时打开 HSI 和 ADC。VREFINT 启动等待由主循环推进。两路各丢弃首个样本，随后用 8 次采样求浮点均值，按 4095 满码和实际 VDDA 换算。采样结束关闭 ADC 和 HSI。无有效测量时保留前次电量，`Battery_ADC_Error_Count` 计数。Keil Watch 可查看 `Battery_Voltage`、`POWER_Vol` 和回退标记。

初始档位分界为 7.20／7.44／7.68／7.92 V。日常降档、升档分别在各分界下方和上方 0.06 V。每五秒采样一次。首次到 7.20 V 或以下时记录欠压，测量页显示“及时充电”350 ms、恢复电量 350 ms、再次显示 350 ms，然后恢复电量。蜂鸣 60 ms 一声，间隔 60 ms，共三声。处于其他菜单时，提示在进入测量页后播放。再次手动开机开始新的一次提醒机会。

## 双板时钟与通信

| 项目 | 配置 |
| --- | --- |
| F103 和 L151 | 外部 8 MHz 晶振直通，PLL 关闭，AHB/APB 不分频 |
| F103 TIM2 | 1 MHz，供位移 I²C 延时和 SPI 等待超时使用 |
| F103 SPI1 倾角 ADC | PA4 片选、PA5 时钟、PA6 数据。模式 3，2 MHz，两字连续发送 |
| 倾角板采集 | SysTick 1 ms，倾角 20 ms，辅助采集和上报 100 ms |
| 串口 | 115200，保持原协议。BRR 取整得到约 115942 baud |
| 主板 I²C1/2、OLED SPI2 | I²C 配置 100 kHz，OLED SPI 配置 2 MHz |

ADC161S626 在第 3～18 个下降沿推出有效数据，SPI 在上升沿采入。程序从两字中还原原有 16 位有符号码。32 个时钟在 2 MHz 下约 16 µs。驱动由 TIM2 限制单次等待，异常时不把错误采样塞进角度滤波，`ADC161_Spi_Error_Count` 记录异常。核对 `CG_Sample_Interval_Ms` 与 `CG_Sample_Overrun_Count` 可检查调度。

主板测量页可每 20 ms 更新。RTC 至多每秒读取一次，文本有变化或切页时才绘制。OLED 将变化的像素范围分批交给 DMA，DMA 使用独立传输缓冲。关机状态不在主循环重复初始化页面。两板空闲执行内核 Sleep，由 1 ms 节拍及串口、DMA 等中断唤醒。正常测量持续更新并常亮。

## 蓝牙

主板图纸 U5 为 VG6328A，接 USART2。启动后给模块留 250 ms 初始化，再发送 AT 指令关闭 BLE 和 SPP 广播。快捷菜单最后一项为“蓝牙开关”，选中后按确认键切换。ON 和 OFF 来自模块确认，ERR 表示配置未得到完整确认或退出失败。

配置期间保留 USART2 二进制接收，对该口的前台数据发送短暂让出时间。每条发送超时 5 ms，等待模块 OK 至多 80 ms，退出命令允许再试一次。蓝牙配置结束后恢复 USART2 通常处理，USART1 的传感器收发独立运行。模块由 3.3 V 直接供电，菜单控制其广播状态。

## 上台检查

1. 在可调电源和负载下，记录 8.2 V、7.9 V、7.4 V、7.2 V 附近和低于阈值时的表读数及 `Battery_Voltage`。过阈值后升压再降压，确认本次开机只有一次告警。
2. 用逻辑分析仪确认 ADC 的 SCK、CS、前两个占位时钟和有效位序。用同一固定姿态对照 CG40/CG41 的原始 AD。连续记录 20 ms 采样、100 ms 报文间隔、CRC 与丢帧计数。检查两个方向的超高示值及响应。
3. 用蓝牙扫描和上位机各验证一次。检查开机不广播、菜单开关与断开模块时的超时，并核对蓝牙开启后的原上位机通信。
4. 0℃ 下录制完整放电曲线，记录开机、第一次欠压和停止正常测量的时间。用实测结果核对连续测量 50 小时和欠压后 8 小时要求，再据结果调整阈值。
