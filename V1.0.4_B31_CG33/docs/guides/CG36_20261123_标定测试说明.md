# CG36 TEST 标定判稳调整

2026-11-23，主控基于 CG35 TEST，配套 CG34 倾角板。

## 烧录与参数

主控 HEX 位于 firmware/CG36_TEST_20261123/STM32L151_CG36_TEST.hex。倾角板已烧录 CG34 的样机，本次烧录主控即可。开机页应显示 CG36 TEST。

参数位于 STM32L151/Software/inc/agreement_head.h。

| 判定项 | 本版数值 | 含义 |
| --- | --- | --- |
| CG_CAL_STABLE_SAMPLES | 10 | 使用最近十帧，取其平均 AD 保存 |
| CG_CAL_STABLE_TIME_MS | 800 ms | 十帧时间跨度下限，为名义 900 ms 留接收计时余量 |
| CG_CAL_STABLE_RANGE_AD | 6 AD | 十帧最大值减最小值的上限 |
| CG_CAL_MAX_MEAN_DRIFT_AD | 2 AD | 后五帧均值与前五帧均值之差的绝对值上限 |
| CG_CAL_MAX_GAP_MS | 250 ms | 相邻有效帧间隔达到该值时重新积累数据 |

前版的 3 AD 峰峰值作为初值偏紧，并且十帧实际时间跨度略低于 900 ms 时会被时间条件拒绝。本版允许较大的来回波动，同时用前后半段均值的变化约束持续漂移。均值差使用未除法截断的整数和比较，2.2 AD 的变化会被正确拒绝。

6 AD 是本次标定判稳测试初值。按默认跨度约 12446 AD 对应 180 mm，6 AD 峰峰值约为 0.087 mm。标定取十帧均值，实际标定误差需要用检定器复测。主界面测量输出采用 2 AD 死区，倾角采样采用 20 ms / 40 点滤波 / 100 ms 发包配置。CG35 的零区间连续性修复继续用于超高计算。

## 等待提示

| 提示 | 对应原因 |
| --- | --- |
| READY | 当前十帧同时满足时间、波动与漂移条件，可以按存储键采集 |
| WAIT DATA | 尚未积累十帧，进入新标定步骤时先等待 |
| WAIT TIME | 十帧时间跨度还不足 800 ms |
| WAIT AD | 十帧峰峰值超过 6 AD |
| WAIT DRFT | 前后五帧均值变化超过 2 AD，数据还在缓慢变化 |
| WAIT LINK | 最近帧间隔或帧年龄达到 250 ms |
| NO SENSOR | 整体传感器链路超时 |
| SAVED | 本点已经采集，页面显示实际保存的 AD 均值 |

## 测试

1. 固定在检定器的当前标定位置，观察 WAIT 提示切换到 READY 的时间。
2. 每个位置等 READY 后按存储键，看到 SAVED 后再按一次进入下一点，按水平、水平掉头、180 mm、180 mm 掉头完成四点。
3. 在最终“存储键保存”画面确认提交并显示“成功”。
4. 回到 0 mm 固定一分钟并掉头复测，记录最大、最小示值，检查用户提出的 ±0.05 mm 目标。测试中间点、左右 180 mm 与两秒内稳定的目标。
5. 若仍难以 READY，记录具体 WAIT 提示，并在主控 Watch 读取 CG_Calibration_Range_AD、CG_Calibration_Trend_AD、CG_Ad 和 Temp。

CG_Calibration_Trend_AD 是前后五帧均值差的绝对值向上取整，便于观察。最终通过判定使用未取整的比较值。
CG_Calibration_Wait_State 依次为 0 READY、1 DATA、2 LINK、3 TIME、4 AD、5 DRIFT。

EEPROM 继续按已有 B3.1 快照恢复和提交标定，已有四点数据可用于启动计算。

## 验证

主控 Keil 全量编译为零错误、零警告。主机串口与标定判稳回归共 72 项通过，覆盖 891 ms 时间抖动、6 AD 波动接受、超范围拒绝、慢漂移、2 / 2.2 AD 均值差边界、短时间窗口、掉线、计时溢出与噪声帧。
CG35 的七组全 AD 范围扫描，以及超高计算、标定保存和失败重试回归通过。当前 Windows GCC 缺少 libubsan，功能测试使用其可用的编译选项。实机 READY 可用性、标定精度和整机响应待本轮测试确认。
