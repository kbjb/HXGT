# B3.1 EEPROM 代码静态检查与回归测试报告

- **版本**：V1.0.4_B31 / 2026-11-04
- **基线**：用户上传的 V1.0.3_B3
- **测试环境**：Linux 主机 GCC C99，`-O1 -g -Wall -Wextra -Werror -fsanitize=undefined -fstack-protector-all`，64 KiB 内存数组模拟 AT24C512；非 ARM/Keil、非真实 I2C 芯片。
- **最终结果**：B3.1 **326 项断言通过**；B2 UART **41 项断言通过**。

## 明确没有做的验证

- **没有**在当前环境执行 Keil ARM Compiler 5、整个 STM32L151 Keil 工程编译；无法声明 ARM 可执行文件已被本机重新构建。
- **没有**连接实物 AT24C512、WP 引脚、I2C 分析仪或电源切换设备；无法声明硬件供电中断与寿命测试通过。
- **没有**重新测量仪表精度，参数默认值不能代替每把尺的标定/检定。
- 记录数据本体仍然没有逐条 CRC；模拟测试能验证写后回读和计数提交，不涵盖 EEPROM 老化后单条记录长期位翻转的检测。

**结论**：B3.1 的 EEPROM 核心软件逻辑及与 B2 UART 的主机端回归通过；硬件量产验收仍需用户按操作说明在 Keil 和实际电路中完成。
