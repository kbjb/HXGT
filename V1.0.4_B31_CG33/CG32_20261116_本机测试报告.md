# V1.0.4_B31_CG32 本机测试报告

测试环境：GCC、UndefinedBehaviorSanitizer (UBSan)、静态源代码检查；**没有 Keil ARM 编译器、ADC161 实物、示波器或整机标定器参与测试**。

执行：`sh CG32_HOST_TESTS/run_cg32_tests.sh`

| 测试项目 | 本机结果 | 主要覆盖 |
|---|---|---|
| 新 CG32 倾角滑动滤波 | PASS，41 项断言 | 首次启动没有零值偏置、3 AD 更新、单点尖峰去除、负32768至正32767、左右 180 对应 AD、往返 |
| ADC161 实际源码串行读码模拟 | PASS，7 组码型 | 18 CLK、16 有效位、正负补码边界、无有符号左移 UB |
| 超高运算和标定流程（实际函数提取后主机编译） | PASS | 左右 ±180 mm、±240 mm 越界、标定斜率拒绝、温度参考、保存失败和重试、掉线不保存 |
| B3.1 EEPROM A/B、写保护和地址布局 | PASS，328 项断言 | 全空白初始化、断电中断恢复、已有快照不重写、坏参数拒绝新写、记录分区不相撞 |
| B2 主控 UART 回归 | PASS，41 项断言 | 帧长度、校验、接收缓冲、异常恢复 |
| B2 倾角板串口与周期发送 | PASS | ACK解析、噪声输入、500ms发送周期 |

**不能据此认定设备精度、温度重复性、传感器数据编码、SPI CLK 时序已经通过实机验收。**

Keil 项目：`STM32L151/MDK-ARM/STM32L151.uvprojx` 与 `QINGJIAOBAN/PROJECT/GuiJuChi.uvprojx`。
